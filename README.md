# IELTS 7+ Mock Library

**IELTS 7+ · Md Salim Shadman · Head of IELTS and Language Teaching**

28 full IELTS Academic mock tests (Listening, Reading and Writing) that run entirely in the browser.

## Use it

Open `index.html`, enter a Student ID, pick a mock, complete the ready check and start.

- The Student ID is entered once and used in every section.
- Security mode (fullscreen lock with a 3-strike rule) is optional; switch it on in the ready check.
- Listening and Reading answers and bands are shown only after the whole mock is finished, with a full answer review.
- Writing responses download as a `.txt` file named with the Student ID, for the teacher to mark.
- Results are saved in the browser. Use **Progress → Export CSV** to collect them.

Works offline too: download the repository, keep `index.html` and the `mocks` folder together, and open `index.html` in Chrome or Edge.

## Structure

```
index.html                      Mock library (choose student, mock, progress, review)
mocks/mock-NN/IELTS_Full_Mock_N.html   Full mock N (Listening, Reading, Writing)
mocks/mock-NN/Listening Full Mock N.mp3 Listening audio for mock N
```
